# Security Policy

## Supported Versions

MedConnect is under active development. Security fixes target
the latest code on the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest `main` | Yes |
| Older commits and development branches | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately through this
repository's Security → Advisories → Report a vulnerability.

Include the following information where available.

- A description of the vulnerability and its potential impact
- The affected component and commit
- Steps to reproduce the issue
- A minimal proof of concept using synthetic data

Keep passwords, access tokens and personal information out
of reports. Please keep vulnerability details private while
we investigate and coordinate a fix.

## Response Process

We aim to acknowledge reports within 7 days and provide an
update at least every 14 days while an investigation is active.

For accepted reports, we will discuss the impact, planned fix
and disclosure timing with the reporter.

If we decline a report, we will explain the reason and invite
additional evidence.
